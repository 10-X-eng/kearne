# Kearne Architecture Prototypes

This directory contains disposable feasibility work, never product code. The root build, packages, and production modules do not include it. Create a prototype only when implementing the production path cannot safely answer a material uncertainty. Promote a result by implementing it under the owning production module; never link or copy the prototype wholesale.
